# rs4rt

We want to build a website that collects different types of initiatives for sharing resources in radiation therapy. We have build a backbone for our website with the following items that could be in boxes in the landing page.
1. Open-source software
a)Registry
b)Form to submit (this will be a google form, link to be provided)
c)Best practices (ex:https://opensource.guide/)
2.Vendors initiatives / Commercial products (ex : Varian website, https://proknowsystems.com/)
3.Data (ex: TCIA, EUCAIM cancerimage.eu, Medical decathlon, cancerdata.org)
4. Clinical guidelines and protocols (ex:https://econtour.org/)
5. Artificial intelligence (ex:DLinRT, https://grand-challenge.org/
6. Education (ex: Youtube channels, Workshops, https://dicom.innolitics.com/ciods)

 We want a footer with contact info (email) and an "about" tab with Description of the initiative and group of people/contributors. 

Can you help us to start with a template for the website?
